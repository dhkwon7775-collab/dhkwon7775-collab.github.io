  • 복비는 법으로 정한 최대 요율 안에서 중개사와 협의해 정해요.
  • 매매 5억 원이면 최대 200만 원, 전세 3억 원이면 최대 90만 원이에요.

  • 파는 사람·사는 사람(집주인·세입자)이 각자 내요.

9억 원, 6억 원 경계를 조심하세요

요율은 구간마다 정해져 있어서, 경계를 살짝 넘으면 복비가 크게 뛰어요.

  • 매매 8억 9,000만 원: 0.4% → 최대 356만 원
  • 매매 9억 원: 0.5% → 최대 450만 원
  • 전세 5억 9,000만 원: 0.3% → 최대 177만 원
  • 전세 6억 원: 0.4% → 최대 240만 원

거래금액이 경계 바로 위라면, 경계 아래 요율 수준으로 협의해 보세요.

월세는 어떻게 계산하나요?

월세는 보증금 + (월세 × 100)을 거래금액으로 봐요. 이 값이 5천만 원보다 적으면 보증금 + (월세 × 70)으로 다시 계산해요.

  • 보증금 1,000만 원, 월세 50만 원: 1,000만 + 5,000만 = 6,000만 원 → 0.4% = 24만 원
  • 보증금 500만 원, 월세 30만 원: 500만 + 3,000만 = 3,500만 원 (5천만 원 미만) → 500만 + 2,100만 = 2,600만 원 → 0.5% = 13만 원

복비 아끼는 법

  1. 계약 전에 협의하세요. 요율은 최대한도예요. 계약서를 쓰기 전에 금액을 정하고 중개 계약서나 문자로 남겨 두세요.
  2. 부가세 포함인지 물어보세요. 일반과세자 중개사무소는 10%를 더 받을 수 있어요. "부가세 포함 얼마"로 확정하는 게 좋아요.
  3. 현금영수증을 받으세요. 현금영수증을 받으면 연말정산 카드 등 소득공제에 들어가요.
  4. 매매 영수증은 보관하세요. 집을 살 때 낸 복비는 나중에 집을 팔 때 양도소득세를 계산하는 비용으로 인정돼요.

자주 묻는 질문

복비는 언제 내나요?

보통 잔금을 치르는 날 내요. 중개사의 잘못으로 계약이 취소되면 내지 않아도 돼요.

요율보다 많이 달라고 하면 어떻게 하나요?

상한요율을 넘는 금액을 받는 것은 공인중개사법 위반이에요. 더 낸 돈은 돌려받을 수 있고, 시·군·구청 부동산 담당 부서에 신고할 수 있어요.

전세를 연장할 때도 복비를 내나요?

집주인과 직접 재계약하면 내지 않아요. 중개사를 통해 새 계약서를 쓰면 협의한 금액을 내요.
